Automatically resolves a recipient's email address from the Outlook history, asks for confirmation (with the option to edit), then strings on the writing of the email. Use as soon as the user mentions sending an email or message to a nominee. Trigger phrases: "send email to", "write a message to", "I want to contact", "send a mail to", "send an email to", "write to", "message to", "contact [first name last name]", "mail for", "email for".
